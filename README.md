# BarOps releases

Installers for **BarOps** — bar stock, sales and daily cash for Windows.

- **New install:** open the [latest release](https://github.com/yogeshguptacodes-cyber/barops-releases/releases/latest), download `BarOps-x.y.z-setup.exe` and run it.
- **Already installed?** Nothing to do. BarOps updates itself whenever the computer is online, and installs the update when it is closed. Your data and licence are never touched.

BarOps needs a licence key made for your computer. Questions: support@barops.in

This repository only holds the installers.
